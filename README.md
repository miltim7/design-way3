# Слой — графический дизайн

Сайт графического дизайнера Николая Парфенкова. Готовые HTML-страницы лежат в корне репозитория.

## Как выложить сайт

Распакуйте архив с сайтом в папку, из которой хостинг отдаёт страницы. Сохраните расположение файлов и папок. Главная страница — `index.html`. Достаточно обычного статического хостинга. Установка зависимостей и сборка не нужны.

- `*.html` — главная, портфолио, страница дизайнера, информационные страницы, формы входа и регистрации, кабинет и 404.
- `assets/globals.css` и `assets/main.js` — стили, меню, галерея, фильтры и формы.
- `assets/content.json` — данные для просмотра работ и каталога.
- `assets/images/`, `assets/videos/` и `assets/fonts/` — изображения, ролики и шрифты.
- `components/` — браузерные скрипты аккаунта, анимаций и видеопревью.

Разметку редактируют прямо в соответствующем HTML-файле. Шапка и подвал входят в разметку каждой страницы. При изменении услуги или работы обновите карточки в HTML и соответствующие данные в `assets/content.json`.

Для Netlify корень репозитория уже настроен как каталог публикации. Файл `_redirects` сохраняет переходы со старых адресов с папками. При переносе на другой хостинг можно добавить такие же правила в его панели.

## Серверные интеграции

Формы заявки, входа и регистрации входят в статический сайт. Для получения заявок и работы аккаунтов на том же домене настройте `POST /api/requests` и маршруты `/api/auth/*`. По возможности проксируйте эти маршруты к отдельному серверному процессу. Совместимая реализация хранится в `backend/`.

Для запуска этой реализации из корня нужны Node.js 20+ и команда `npm start`. Она обслуживает готовые страницы и API. Локальный адрес по умолчанию — `http://127.0.0.1:4173/`.

- Для входа и регистрации настройте постоянное хранилище `ACCOUNT_DATA_FILE` и `PUBLIC_ORIGIN`. Сервер рассчитан на один процесс с постоянным диском. Пароли хранятся в виде хешей scrypt, токены сеансов — в виде хешей SHA-256.
- Для заявок проверьте контактные данные и документы, подтвердите готовность в `backend/config.mjs` и задайте `REQUEST_PROVIDER=webhook` и HTTPS-адрес `REQUEST_WEBHOOK_URL` по примеру в `.env.example`. Отправка считается успешной при HTTP 2xx и подтверждении в JSON.
- Задайте секреты в окружении серверного процесса. Храните `.env`, файлы аккаунтов и резервные копии вне веб-каталога.

Проверка ссылок и файлов — `npm run check`. Тесты интерфейса и API — `npm test`. Эти команды нужны только для разработки и проверки.
