# Вход, регистрация и кабинет

## Маршруты

| Маршрут | Содержание |
| --- | --- |
| `/sign-in/` | Email, пароль, показ пароля и переход на регистрацию |
| `/sign-up/` | Контакты и согласия, затем пароль и его повтор |
| `/account/` | Личные данные, смена пароля, выход и переход к услугам |

Пользователь задаёт пароль при регистрации. Минимальная длина — 10 символов, максимальная — 128. Контактные поля: имя, email, телефон, компания и часовой пояс. Телефон и компания необязательны. Согласия ведут на информационные страницы проекта.

## Поведение

Поля имеют видимые подписи, autocomplete и связанные сообщения об ошибках. Первая ошибка получает фокус. Кнопки показа пароля передают своё состояние. На время запроса кнопка отправки блокируется; успешное состояние появляется после подтверждения API. При ошибке можно повторить запрос. Ответ 401 при загрузке кабинета переводит на вход.

Кабинет позволяет редактировать имя, телефон, компанию и часовой пояс. Email доступен для чтения. Для смены пароля нужны текущий и новый пароли. Смена пароля отзывает остальные сессии.

## Реализация

Разметка: `src/account-pages.mjs`. Клиентское поведение: `public/account.js`. API и хранилище: `src/accounts.mjs` и `server.mjs`. Стили наследуют общую систему из DESIGN.md и public/styles.css.

На статическом размещении маршруты кабинета перенаправляются на вход правилами netlify.toml. После подключения API аккаунтов перенаправления удаляются. История заказов, платежи, подтверждение email и восстановление пароля по почте требуют отдельных интеграций.
