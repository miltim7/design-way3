Техническая сводка сайта «слой»

Графический дизайн, анимация и материалы для маркетплейсов. Владелец и дизайнер — Николай Парфенков.

Реализация

HTML-страницы собираются из JavaScript-шаблонов. Интерфейс использует CSS и обычный JavaScript. Общие шапка и футер подключаются ко всем страницам.

Каталог содержит 16 услуг, портфолио — 13 демонстрационных примеров. Главная показывает краткую задачу каждого примера; /portfolio/ раскрывает задачу, решение и материалы. Страница /about/ знакомит с дизайнером на основе подтверждённых сведений. Обе страницы доступны из общей навигации и футера.

Доступны фильтры, просмотр изображений и видео, сравнение фотографии до и после обработки и переход к заявке с выбранной услугой. Согласованная биография, реальное фото и подтверждённые оригинальные проекты добавляются через данные проекта; порядок описан в portfolio-content.md.

Медиа

Ролики проигрываются без звука в видимых карточках, имеют кнопку паузы и останавливаются вне экрана. Ролик о доставке не содержит аудио; музыкальный пример содержит оригинальную музыку. Для уменьшенного движения предусмотрен постер с ручным запуском.

Проверки

Команды: npm run build, npm run check, npm test. Автоматические проверки охватывают одиннадцать HTML-страниц и 30 тестов аккаунтов, заявок, анимаций, каталога и видео.

В ходе разработки проверены ширины 320, 390, 768, 1265 и 1440 px, включая страницы дизайнера и подробного портфолио. Перечень проверок и их границы: verification.md.

Серверные интеграции

Для API аккаунтов и заявок нужен Node-хостинг с постоянным хранилищем или маршрутизация API к серверу. Настройка webhook, PUBLIC_ORIGIN, контактов и документов описана в README.md. История заказов, платежи, файловый обмен и восстановление пароля по почте подключаются отдельно.
