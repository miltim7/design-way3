Техническая сводка сайта «слой»

Проверка локальной сборки: 27 октября 2026 года.

Графический дизайн, анимация и материалы для маркетплейсов. Владелец и дизайнер — Николай Парфенков.

Реализация

HTML-страницы собираются из JavaScript-шаблонов. Интерфейс использует CSS и обычный JavaScript. Общие шапка и футер подключаются ко всем страницам.

Каталог содержит 16 услуг, портфолио — 29 проектов: 10 с предоставленными работами Николая и 19 демонстрационных примеров. На главной показаны восемь проектов на странице: четыре страницы, на последней пять работ; первая восьмёрка видима уже в собранном HTML. На /portfolio/ все 29 проектов видны сразу; происхождение хранится в данных и документации, без публичных переключателей и пометок. Предоставленные материалы имеют kind: 'provided'; подтверждённых заказных проектов с kind: 'client' нет. Главная показывает краткую задачу; /portfolio/ раскрывает задачу, решение и материалы. Страница /about/ знакомит с дизайнером на основе подтверждённых сведений. Обе страницы доступны из общей навигации и футера.

Все шесть фильтров, включая «Все направления», постоянно доступны и выбирают только направление дизайна; стрелки просмотра учитывают текущий видимый набор независимо от происхождения, на главной — текущую страницу. Категория возвращает на первую страницу и пересчитывает страницы, при одной странице пагинация скрыта. Переключение переносит фокус и прокрутку к заголовку; reduced motion использует мгновенную прокрутку. Заголовок на главной — «От упаковки до обложки: примеры дизайна», в портфолио — «Дизайн в деталях». У фестиваля 10 изображений, у журнала семь: горизонтальные миниатюры со счётчиком позволяют рассмотреть материалы отдельно. Доступны просмотр видео, сравнение фотографии до и после обработки и переход к заявке с выбранной услугой. Состав материалов и порядок обновления описаны в portfolio-content.md.

Медиа

Из 30 предоставленных изображений работ отобраны 25; отдельный настоящий портрет используется на главной и странице дизайнера без ретуши. Исходники находятся в assets-original/designer/, манифест — src/designer-assets.json. Скрипт scripts/designer-assets.mjs создаёт 78 WebP и 78 JSON о происхождении без увеличения меньших исходников и без изменения композиций. Переданный архив сохраняется отдельно без изменений.

Дополнительные примеры: стиль пекарни, айдентика архитектурного бюро, упаковка чая, свадебное приглашение, джазовая афиша и серия карточек рюкзака. Это демонстрационные материалы с русскими надписями, не заказные работы. Исходные PNG, точные запросы и повторная оптимизация описаны в additional-portfolio-assets.md. Широкая серия карточек помещается в галерее целиком; полный просмотр сохраняет края изображения.

Ролики проигрываются без звука в видимых карточках, имеют кнопку паузы и останавливаются вне экрана. Ролик о доставке не содержит аудио; музыкальный пример содержит оригинальную музыку. Для уменьшенного движения предусмотрен постер с ручным запуском.

Проверки

Команды npm run build, npm run check, npm test выполнены успешно: одиннадцать HTML-страниц и 37 тестов аккаунтов, заявок, анимаций, каталога, видео, портфолио и пагинации. Проверка HTML подтверждает восемь изначально видимых проектов на главной и 29 на /portfolio/.

Текущий проход пагинации по восемь работ: главная при 1440 px показывает четыре страницы, на последней пять работ с диапазоном 25–29. При 320 px видны восемь работ без переполнения; при 768 px восемь работ занимают две равные колонки без переполнения. Полиграфия содержит две страницы по восемь и две работы, диапазон последней — 9–10. На /portfolio/ все 29 проектов сохранены без пагинации. Три снимка находятся в .impeccable/review/gallery-eight/. Единственный запуск детектора этого прохода записан в artifacts/gallery-eight-detector.json: 295 рекомендательных замечаний, обязательных замечаний нет.

Предыдущий проход пагинации по шесть работ: главная при 1440 px на первой и последней страницах, при 320 px без переполнения с областями нажатия не менее 44 px и при 768 px со второй страницей из шести работ в двух колонках. Проверены две страницы полиграфии с четырьмя работами на последней, две работы анимации без пагинации и возврат «Все направления» к первой шестёрке. Четыре исторических снимка находятся в .impeccable/review/gallery-pagination/. Отчёт artifacts/gallery-pagination-detector.json содержит 295 рекомендательных замечаний без обязательных.

Ранее, после объединения галереи, проверены главная и портфолио при 1440 px, главная при 320 px, портфолио при 390 и 768 px, смешанный фильтр полиграфии, просмотр журнала до 7/7 и переход от обложки релиза к примеру кофе 11/29. Переполнения не обнаружено; сохранены шесть снимков в .impeccable/review/unified-gallery/. Отмена устаревшей загрузки и повторная попытка покрыты автоматическими тестами. Более ранние 14 снимков страницы дизайнера и портфолио остаются историческим свидетельством прежнего прохода. Перечень проверок и их границы: verification.md.

Серверные интеграции

Для API аккаунтов и заявок нужен Node-хостинг с постоянным хранилищем или маршрутизация API к серверу. Для статического хостинга в netlify.toml заданы перенаправления кабинета на вход; если правила хостингом не применены, вход открывает account.js при недоступном API. Настройка webhook, PUBLIC_ORIGIN, контактов и документов описана в README.md. История заказов, платежи, файловый обмен и восстановление пароля по почте подключаются отдельно. Локальная приёмка не подтверждает подключение production API или публикацию обновлённой сборки.
