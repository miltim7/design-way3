Техническая сводка сайта «слой»

Проверка локальной сборки: 27 октября 2026 года.

Графический дизайн, анимация и материалы для маркетплейсов. Владелец и дизайнер — Николай Парфенков.

Реализация

HTML-страницы собираются из JavaScript-шаблонов. Интерфейс использует CSS и обычный JavaScript. Общие шапка и футер подключаются ко всем страницам.

Каталог содержит 16 услуг, портфолио — 29 проектов: 10 с предоставленными работами Николая и 19 демонстрационных примеров. По умолчанию выбраны «Работы Николая 10», отдельно доступны «Примеры услуг 19». Предоставленные материалы имеют kind: 'provided'; подтверждённых заказных проектов с kind: 'client' нет. Главная показывает краткую задачу; /portfolio/ раскрывает задачу, решение и материалы. Страница /about/ знакомит с дизайнером на основе подтверждённых сведений. Обе страницы доступны из общей навигации и футера.

Пустые категории скрываются, смена подборки сбрасывает категорию, стрелки просмотра учитывают видимые проекты. У фестиваля 10 изображений, у журнала семь: горизонтальные миниатюры со счётчиком позволяют рассмотреть материалы отдельно. Доступны просмотр видео, сравнение фотографии до и после обработки и переход к заявке с выбранной услугой. Состав материалов и порядок обновления описаны в portfolio-content.md.

Медиа

Из 30 предоставленных изображений работ отобраны 25; отдельный настоящий портрет используется на главной и странице дизайнера без ретуши. Исходники находятся в assets-original/designer/, манифест — src/designer-assets.json. Скрипт scripts/designer-assets.mjs создаёт 78 WebP и 78 JSON о происхождении без увеличения меньших исходников и без изменения композиций. Переданный архив сохраняется отдельно без изменений.

Дополнительные примеры: стиль пекарни, айдентика архитектурного бюро, упаковка чая, свадебное приглашение, джазовая афиша и серия карточек рюкзака. Это демонстрационные материалы с русскими надписями, не заказные работы. Исходные PNG, точные запросы и повторная оптимизация описаны в additional-portfolio-assets.md. Широкая серия карточек помещается в галерее целиком; полный просмотр сохраняет края изображения.

Ролики проигрываются без звука в видимых карточках, имеют кнопку паузы и останавливаются вне экрана. Ролик о доставке не содержит аудио; музыкальный пример содержит оригинальную музыку. Для уменьшенного движения предусмотрен постер с ручным запуском.

Проверки

Команды npm run build, npm run check, npm test выполнены успешно: одиннадцать HTML-страниц и 35 тестов аккаунтов, заявок, анимаций, каталога, видео и портфолио.

Итоговый браузерный проход охватил ширины 320, 390, 768, 1265 и 1440 px, включая страницы дизайнера и подробного портфолио, выбор материалов, отмену устаревшей загрузки и повторную попытку. Переполнения, предупреждений и ошибок консоли не обнаружено; сохранены 14 снимков. Перечень проверок и их границы: verification.md.

Серверные интеграции

Для API аккаунтов и заявок нужен Node-хостинг с постоянным хранилищем или маршрутизация API к серверу. На статическом Netlify маршруты кабинета перенаправляются на вход кодом 302. Настройка webhook, PUBLIC_ORIGIN, контактов и документов описана в README.md. История заказов, платежи, файловый обмен и восстановление пароля по почте подключаются отдельно. Локальная приёмка не подтверждает подключение production API или публикацию обновлённой сборки.
