# Проверка проекта

## Команды

```powershell
npm run build
npm run check
npm test
```

## Автоматические проверки

- Сборка одиннадцати HTML-страниц, внутренних ссылок, якорей, медиа, srcset, уникальности ID и ARIA-связей; шесть изначально видимых проектов на главной и все 29 на `/portfolio/` без пагинации.
- Регистрация, вход, сохранение профиля, хеширование паролей, сессии, смена пароля и выход.
- Валидация заявок, подтверждение webhook, ошибки, ограничения частоты и защита от дублирования.
- Отмена анимаций, reduced motion, мобильный каталог и появление при прокрутке.
- MIME-типы видео и субтитров, диапазоны байтов и запросы HEAD.
- Беззвучные превью: запуск в видимой области, остановка вне экрана и за модалкой, ручная пауза и позднее завершение play().

Набор содержит 37 тестов. На 27 октября 2026 года успешно выполнены сборка, проверка одиннадцати страниц и все 37 тестов. Семь тестов `tests/portfolio.test.mjs` проверяют общую галерею с фильтрацией только по направлению дизайна, стрелки по смешанному видимому набору и переход с последнего проекта к первому, сброс прокрутки миниатюр, отмену устаревшей загрузки и повторную попытку после ошибки. Два новых теста покрывают по шесть работ на странице, последнюю страницу, сброс и пересчёт при смене категории, скрытие пагинации для одной страницы, перенос фокуса и reduced motion. Следующий запуск оценивается по выводу команды `npm test`.

## Интерфейс

Текущий проход пагинации 27 октября: главная при 1440 px на первой и последней страницах (шесть и пять работ), при 320 px без горизонтального переполнения с областями нажатия не менее 44 px и при 768 px со второй страницей из шести работ в двух колонках. Проверены две страницы полиграфии с четырьмя работами на последней, две работы анимации без пагинации и возврат «Все направления» к первой шестёрке. На `/portfolio/` сохранены все 29 проектов без пагинации. Фокус возвращается к заголовку; reduced motion отключает плавную прокрутку. Четыре снимка — `.impeccable/review/gallery-pagination/first-desktop.png`, `last-desktop.png`, `mobile-320.png`, `tablet.png`.

Ранее, после объединения галереи 27 октября, проверены главная и `/portfolio/` при 1440 px, главная при 320 px, портфолио при 390 и 768 px, все шесть фильтров и смешанный набор полиграфии из 10 проектов. Проверены просмотр журнала до 7/7 и переход с обложки музыкального релиза к следующему примеру кофе со счётчиком 11/29. Горизонтального переполнения не обнаружено. Шесть снимков в `.impeccable/review/unified-gallery/` отражают галерею до добавления пагинации. Все 29 проектов, исходная сцена первого экрана и 16 услуг сохранены. Отмена устаревшей загрузки и повторная попытка проверены автоматическими тестами. Более ранний проход при 320/390/768/1265/1440 px охватывал главную, `/about/`, `/portfolio/`, настоящий портрет, изображения, материалы фестиваля и журнала и выбор услуги; 14 исторических снимков находятся в `.impeccable/review/final-real/` и отражают прежний интерфейс с разделением по происхождению. Проверки выполнялись в браузере на Windows; физические устройства и другие браузерные движки требуют отдельного прогона.

Для шести дополнительных демонстраций ранее проверены названия и изображения в просмотре, задачи и материалы, связанные услуги и переход карточек рюкзака к `marketplace-card`. Все три слайда рюкзака видны целиком в галерее и просмотре. Снимки этого прохода сохранены в `.impeccable/review/portfolio-added/`. Повторный запуск `scripts/additional-portfolio-assets.mjs` сохраняет запросы во всех 18 JSON рядом с WebP; проверка происхождения охватывает также шесть исходных PNG.

Предоставленные материалы: 25 записей манифеста, 26 исходников с портретом, 78 WebP и 78 JSON о происхождении. Sharp не увеличивает меньшие оригиналы; композиции и надписи сохранены. Единственный запуск детектора для пагинации записан в `artifacts/gallery-pagination-detector.json`: 295 рекомендательных замечаний, обязательных замечаний нет. Более ранний отчёт объединённой галереи `artifacts/unified-gallery-detector.json` содержит 290 рекомендательных замечаний без обязательных; по визуальному просмотру того прохода дефектов, требовавших изменения интерфейса, не выявлено, были исправлены устаревшие описания проекта. Отчёт `artifacts/final-real-detector.json` содержит 301 рекомендательное замечание и относится к ещё более раннему проходу.

## Проверки интеграций при развёртывании

Локальная проверка не подтверждает подключение production API или публикацию новой сборки. Проверить HTTPS и PUBLIC_ORIGIN, постоянное хранилище аккаунтов, получение заявки webhook, обработку отказа и таймаута, подтверждение отправки, контакты и реквизиты в информационных документах. В `netlify.toml` заданы перенаправления кабинета на вход. В опубликованной версии 27 октября HTML кабинета возвращался без HTTP-перенаправления; браузерный `account.js` корректно открывал `/sign-in/` при недоступном API, форма входа видима. Переменные среды и порядок подключения описаны в README.md.
