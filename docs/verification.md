# Проверка проекта

## Команды

```powershell
npm run build
npm run check
npm test
```

## Автоматические проверки

- Сборка одиннадцати HTML-страниц, внутренних ссылок, якорей, медиа, srcset, уникальности ID и ARIA-связей.
- Регистрация, вход, сохранение профиля, хеширование паролей, сессии, смена пароля и выход.
- Валидация заявок, подтверждение webhook, ошибки, ограничения частоты и защита от дублирования.
- Отмена анимаций, reduced motion, мобильный каталог и появление при прокрутке.
- MIME-типы видео и субтитров, диапазоны байтов и запросы HEAD.
- Беззвучные превью: запуск в видимой области, остановка вне экрана и за модалкой, ручная пауза и позднее завершение play().

Набор содержит 35 тестов. На 27 октября 2026 года успешно выполнены сборка, проверка одиннадцати страниц и все 35 тестов. Пять тестов `tests/portfolio.test.mjs` проверяют общую галерею с фильтрацией только по направлению дизайна, стрелки по смешанному видимому набору и переход с последнего проекта к первому, сброс прокрутки миниатюр, отмену устаревшей загрузки и повторную попытку после ошибки. Следующий запуск оценивается по выводу команды `npm test`.

## Интерфейс

После объединения галереи 27 октября проверены главная и `/portfolio/` при 1440 px, главная при 320 px, портфолио при 390 и 768 px, все шесть фильтров и смешанный набор полиграфии из 10 проектов. Проверены просмотр журнала до 7/7 и переход с обложки музыкального релиза к следующему примеру кофе со счётчиком 11/29. Горизонтального переполнения не обнаружено. Шесть снимков сохранены в `.impeccable/review/unified-gallery/`. Все 29 проектов, исходная сцена первого экрана и 16 услуг сохранены. Отмена устаревшей загрузки и повторная попытка проверены автоматическими тестами. Более ранний проход при 320/390/768/1265/1440 px охватывал главную, `/about/`, `/portfolio/`, настоящий портрет, изображения, материалы фестиваля и журнала и выбор услуги; 14 исторических снимков находятся в `.impeccable/review/final-real/` и отражают прежний интерфейс с разделением по происхождению. Проверки выполнялись в браузере на Windows; физические устройства и другие браузерные движки требуют отдельного прогона.

Для шести дополнительных демонстраций ранее проверены названия и изображения в просмотре, задачи и материалы, связанные услуги и переход карточек рюкзака к `marketplace-card`. Все три слайда рюкзака видны целиком в галерее и просмотре. Снимки этого прохода сохранены в `.impeccable/review/portfolio-added/`. Повторный запуск `scripts/additional-portfolio-assets.mjs` сохраняет запросы во всех 18 JSON рядом с WebP; проверка происхождения охватывает также шесть исходных PNG.

Предоставленные материалы: 25 записей манифеста, 26 исходников с портретом, 78 WebP и 78 JSON о происхождении. Sharp не увеличивает меньшие оригиналы; композиции и надписи сохранены. Для объединённой галереи один запуск детектора записан в `artifacts/unified-gallery-detector.json`: 290 рекомендательных замечаний, обязательных замечаний нет. По итоговому визуальному просмотру дефектов, требующих изменения интерфейса, не выявлено; скорректированы устаревшие описания проекта. Предыдущий отчёт `artifacts/final-real-detector.json` содержит 301 рекомендательное замечание и относится к прежнему проходу.

## Проверки интеграций при развёртывании

Локальная проверка не подтверждает подключение production API или публикацию новой сборки. Проверить HTTPS и PUBLIC_ORIGIN, постоянное хранилище аккаунтов, получение заявки webhook, обработку отказа и таймаута, подтверждение отправки, контакты и реквизиты в информационных документах. В `netlify.toml` заданы перенаправления кабинета на вход. В опубликованной версии 27 октября HTML кабинета возвращался без HTTP-перенаправления; браузерный `account.js` корректно открывал `/sign-in/` при недоступном API, форма входа видима. Переменные среды и порядок подключения описаны в README.md.
