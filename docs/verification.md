# Проверка проекта

## Команды

```powershell
npm run build
npm run check
npm test
```

## Автоматические проверки

- Сборка одиннадцати HTML-страниц, внутренних ссылок, якорей, медиа, srcset, уникальности ID и ARIA-связей.
- Регистрация, вход, сохранение профиля, хеширование паролей, сессии, смена пароля и выход.
- Валидация заявок, подтверждение webhook, ошибки, ограничения частоты и защита от дублирования.
- Отмена анимаций, reduced motion, мобильный каталог и появление при прокрутке.
- MIME-типы видео и субтитров, диапазоны байтов и запросы HEAD.
- Беззвучные превью: запуск в видимой области, остановка вне экрана и за модалкой, ручная пауза и позднее завершение play().

Набор содержит 30 тестов. Результат актуального запуска следует проверять по выводу команды `npm test`.

## Интерфейс

В ходе разработки проверены ширины 320, 390, 768, 1265 и 1440 px: границы контента, переносы, меню, фильтры, выбор услуги в заявке, просмотр изображения, воспроизведение видео и сравнение фотографий. Для `/about/` и `/portfolio/` проверены навигация, отсутствие горизонтального переполнения, последовательность изображения и пояснения на мобильном экране, подробные описания и переход к заявке. На главной сохранены все прежние 13 примеров и исходная сцена первого экрана; с шестью дополнительными примерами обе галереи содержат 19 демонстраций. Проверка выполнялась в браузере на Windows; физические устройства и другие браузерные движки требуют отдельного прогона.

Для шести дополнительных примеров проверены названия и изображения в просмотре, задачи и материалы, существующие связанные услуги и переход карточек рюкзака к `marketplace-card`. Все три слайда рюкзака видны целиком в галерее и просмотре. Снимки главной, подробного портфолио, просмотра пекарни и рюкзака, мобильной, планшетной и узкой вёрстки сохранены в `.impeccable/review/portfolio-added/`. Повторный запуск `scripts/additional-portfolio-assets.mjs` сохраняет запросы во всех 18 JSON рядом с WebP; проверка происхождения охватывает также шесть исходных PNG. После расширения успешно выполнены сборка, проверка одиннадцати HTML-страниц и все 30 тестов.

## Проверки интеграций при развёртывании

Проверить HTTPS и PUBLIC_ORIGIN, постоянное хранилище аккаунтов, получение заявки webhook, обработку отказа и таймаута, подтверждение отправки, контакты и реквизиты в информационных документах. Переменные среды и порядок подключения описаны в README.md.
