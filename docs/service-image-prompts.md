# Изображения услуг

20 октября 2026. По запросу пользователя добавлены отдельные наглядные изображения к 12 услугам. Созданы встроенным ImageGen, отдельным запросом для каждой услуги; не являются клиентскими работами.

Точные запросы, идентификаторы и русские альтернативные подписи: `src/service-art.json`.

Оригиналы: `assets-original/services/<id>.png`.
Версии для сайта: `public/assets/services/<id>-640.webp` и `<id>-960.webp`.
Повторная оптимизация: `node scripts/service-images.mjs`.

| Услуга | Что изображено |
| --- | --- |
| Логотип базовый | Простой кофейный знак и эскиз |
| Логотип премиум | Согласованный набор фирменного стиля |
| Дизайн этикетки | Банка и развёрнутая этикетка |
| Рекламный баннер | Рекламный макет с кроссовком |
| Обложка релиза | Квадратная обложка и винил |
| Анимированный логотип | Последовательные кадры появления знака |
| Интерфейсная анимация | Переход между состояниями приложения |
| Дизайн открытки | Иллюстрированная открытка и конверт |
| Дизайн сертификата | Оформленный подарочный сертификат |
| Дизайн стикеров | Набор фигурных наклеек |
| Дизайн постера | Вертикальная афиша |
| Дизайн меню | Открытый разворот ресторанного меню |

Изображения двух анимационных услуг — статичные поясняющие раскадровки. Названия вымышленных брендов внутри иллюстраций служат только демонстрацией типографики. Изображения первого экрана переиспользуют три ранее созданные концепции; запросы сохранены в `docs/image-prompts.md`.
