# Информационные страницы

Каталог содержит HTML-фрагменты четырёх страниц:

- `privacy-policy.html` — политика конфиденциальности;
- `offer-agreement.html` — условия заказа;
- `delivery.html` — доставка файлов и способы оплаты;
- `payment.html` — информация об оплате.

Пути задаются в `site.documents` файла `src/config.mjs`. Сборщик добавляет к фрагментам общую шапку, футер, заголовок и стили проекта. `sources.json` содержит локальные пути и SHA-256 текущих файлов.

В документах указан Николай Парфенков. Email `info@example.com` и телефон из нулей — заполнители для внесения действующих контактов. Реквизиты исполнителя заполняются подтверждёнными данными владельца. Платёжный шлюз подключается отдельно.
